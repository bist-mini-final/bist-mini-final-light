# BI 실습용 가상 기업 데이터

사용자가 제공한 **가상 기업과 가상 수치**를 새 표 형식으로 옮긴 18개 Excel입니다.
유료 원본 템플릿의 디자인·매크로·외부 연결·공급사 전용 메타데이터는 포함하지 않습니다.
원본 파일은 수정하거나 배포하지 않습니다. 실제 기업의 공시나 투자 판단 자료가 아닙니다.

각 파일은 손익계산서, 재무상태표, 현금흐름표 3개 시트와 FY2021–FY2025를 담습니다.
금액 단위는 USD 백만이며, 파일별 지표·값·SHA-256은 `manifest.json`에서 확인합니다.
매출 및 성장, 수익성, 현금흐름, 재무 안정성, 재무 규모, 재무 체력 히트맵의 모든 필수 지표를 제공합니다.
히트맵은 화면의 **카드 추가**에서 선택할 수 있습니다.

## 한 번에 적재

앱을 실행한 상태에서 같은 저장소와 `.env`를 사용하는 별도 터미널에서 실행합니다.

```bash
uv run python scripts/load_bi_samples.py
```

첫 파일만 확인하려면 `--limit 1`을 추가합니다. 같은 파일과 해시의 인덱스는 재사용합니다.
Excel 업로드·구조 분석·임베딩·pgvector 저장은 일반 적재 경로를 사용합니다.
설정 화면에서 선택한 VLM과 임베딩 모델이 필요하며 OpenAI를 선택했다면 API 비용이 발생합니다.

대시보드는 샘플 파일의 실제 셀과 manifest를 대조한 뒤 기존 BI 계산기로 생성합니다.
이 단계는 **LLM 지표 추출을 생략한 재현 가능한 실습 데이터 준비**이며,
화면 상태 메시지에도 이 사실을 표시합니다. 셀 근거와 파생 지표 공식을 확인할 수 있습니다.
전체 RAG 기반 지표 추출을 연습하려면 화면에서 **데이터 초기화 및 재생성**을 실행하세요.

## 결측과 추가 데이터

제공 자료에 없는 단기차입금은 빈 셀로 유지합니다. 0으로 채우지 않습니다.
총차입금은 자료에 있는 값을 사용하므로 모든 카드의 필수 지표를 계산할 수 있습니다.
FY2021 매출 성장률은 이전 연도 비교 대상이 없어 계산하지 않습니다.

`data_archive.json`에는 제공 자료의 손익·재무상태·현금흐름 수치 4,846개 지표 행을
회사·항목·결산일·값으로 정규화했습니다. BI 요약 Excel 밖의 과거·미래 가상 기간도 포함합니다.
이 파일은 추가 데이터 실습용이며 자동 적재 대상은 위 18개 Excel입니다.
공급사 코드, 템플릿 안내, 매크로, 숨겨진 시트와 유료 서식은 이 아카이브에도 포함하지 않습니다.
